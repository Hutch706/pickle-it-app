# Pickle It

A phone-first maintenance tracker for the things you own: vehicles, home, health and finance. It is an installable web app that works offline. There is no server and no account; everything you enter stays in your own browser.

Open it: https://hutch706.github.io/pickle-it-app/

To install it on a phone or computer, open that address and use your browser's Add to Home Screen or Install option.
